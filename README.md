# Nicola De Lillo — Game Development Portfolio v2

This version has a general homepage and a separate detailed Reve case study.

## Run locally
From this folder:

```bash
python -m http.server 8000
```

Open `http://localhost:8000`.
Stop with `Ctrl + C`.

## Replace placeholders
Search HTML for:
- YOUR_GITHUB_USERNAME
- YOUR_REVE_REPOSITORY
- YOUR_LINKEDIN_SLUG
- YOUR_EMAIL@example.com
